# Data sources

The original satellite datasets used in this study are publicly available:

- [MOD09GA V6.1 — Terra surface reflectance](https://doi.org/10.5067/MODIS/MOD09GA.061)
- [MYD09GA V6.1 — Aqua surface reflectance](https://doi.org/10.5067/MODIS/MYD09GA.061)
- [MCD12Q1 V6.1 — Terra/Aqua land cover](https://doi.org/10.5067/MODIS/MCD12Q1.061)
